📋 Como preparar la jornada de votacion

1

📱 Crear la red WiFi en el celular del hotspot

Toma un celular Android (el que hara de punto de acceso). Ve a Ajustes → Conexiones → Zona WiFi (o "Punto de acceso movil", segun la marca). Activa el interruptor y configura la red con estos datos:

• Nombre de la red (SSID): Vote4Tech_Urna
• Contrasena: voto2025

Usa siempre estos mismos datos para que el sistema funcione correctamente.

2

💻 Conectar el portatil del servidor a la red

En el portatil donde corre el servidor, abre la lista de redes WiFi y conectate a Vote4Tech_Urna con la contrasena voto2025. Asegurate de tener buena senal.

3

📦 Levantar el servidor Docker

Abre PowerShell en la carpeta Vote4TechServidorLocalUrna y ejecuta:

docker compose up -d

Espera entre 30 y 60 segundos mientras los contenedores inician.

⚠️ Importante: el portatil debe tener conexion a internet en este momento, porque el servidor descarga automaticamente los datos electorales del sistema central al arrancar. Sin internet, la sincronizacion fallara y deberas hacerla manual desde la pestana Sincronizacion una vez tengas conexion.

Cuando esten listos, abre esta misma pagina en el navegador usando la IP del portatil en la red, por ejemplo:

http://192.168.43.21:8081

Puedes ver la IP del portatil ejecutando ipconfig en PowerShell y buscando el adaptador de red inalambrica.

4

📱 Conectar la tablet de urna a la red

En cada tablet o celular que se usara para votar, ve a Ajustes → WiFi y conectate a la red Vote4Tech_Urna con la contrasena voto2025.

5

⚙️ Configurar la app de urna

En la app de urna, desde la pantalla de identificacion toca el boton ⚙️ Configuracion para iniciar sesion con tus credenciales. Luego en el panel de administracion toca Conexion al Servidor, escribe la URL del portatil (por ejemplo http://192.168.43.21:8081), toca Conectar y cargar mesas, selecciona tu mesa y guarda.

6

🔄 Verificar la sincronizacion de datos

El servidor sincroniza los datos electorales automaticamente al arrancar (si habia conexion a internet en ese momento). Puedes verificarlo en la pestana Sincronizacion: si la Ultima descarga muestra una fecha reciente, todo esta listo.

Si la sincronizacion automatica fallo (por falta de internet al arrancar), conecta el portatil a internet y usa el boton Descargar datos electorales para hacerlo manualmente. Esto es necesario antes de empezar la jornada.

7

📤 Al terminar la jornada: subir los votos

Cuando la jornada haya terminado, en la pestana Sincronizacion toca Subir votos al central. Esto envia todos los votos registrados localmente al sistema central. Asegurate de tener conexion al sistema central antes de hacerlo.
